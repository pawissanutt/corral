# corral v0.3.0

Minor release on top of [v0.2.0](v0.2.0.md). Supported targets, installers,
runtime prerequisites, and signing limits are unchanged; see
[installation](../guide/install.md).

## PM coordination

- Coordinate scoped PM work and refresh live PM policy without restarting.
- Bind each PM promotion option to its own authority, and bind dispatch to
  scoped authority. Plan progress is projected onto the board.
- Wake PM subscriptions on coordination outcomes. Preserve owner answers
  during concurrent PM presentation and setup startup context during policy
  refresh.
- Stop re-delivering PM policy after opaque paste outcomes.

## Operating mode and settings

- Unify the operating-mode CLI around a confirmed, finite policy.
- Normalize config key paths before enforcing operating policy.
- Cache Settings config provenance and skip unchanged revalidation.

## Performance

- Build the board snapshot on the sync worker.
- Cache parsed events between event-log reads and reuse shared events.
- Parse only appended transcript lines when refreshing usage, and evict unused
  transcript cache entries.
- Skip rebuilding the search index when its inputs are unchanged, and keep
  changed refreshes incremental.

## Fixes

- Report an unreadable event log against each active usage task.
- Use Darwin-compatible script arguments in terminal regressions.

## Publication

Follow the [release runbook](README.md): the `v0.3.0` tag push reruns the
validation and native matrix and publishes only after every job passes.
