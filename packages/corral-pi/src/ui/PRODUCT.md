# Corral Pi native workbench

Platform: terminal UI. Production rich sessions run the existing Pi InteractiveMode and HostSession; there is no browser runtime or web service.

Confirmed owner direction (A-9/g1/i8–i14): OpenCode-inspired panels, real working UI/backing, responsive sidebar that becomes inline metadata, and preservation of draft/selection. Owner explicitly requested implementation in the actual TUI rather than more mockups or filing alone.

Primary action: compose and inspect live work. Information priorities: conversation/input, bound identity and current state, then contextual resources/progress. The current slice adds native layout, context/plan/job/auxiliary inspection, persistent searchable Changes and Activity main views, captured hunk-to-draft references, and click-to-expand terminal images (owner inputs i17–i19). Larger workspace views and new functional contracts remain separate.

Authoritative data, identity, capabilities, receipts and owner decisions remain Corral/Pi-owned. No simulated completion, role switching or permission controls.
