# Native live session surface

Mode: Operate.

THESIS: Operate a bound corral-pi session from its terminal workbench.
OWN-WORLD: Terminal-owned type, graphite filled regions, single-cell borders, restrained blue focus, explicit semantic state labels.
STORY: Read real streamed work, type into the real composer, inspect native context/progress/Git state without leaving the bound session.
FIRST VIEWPORT: Branded binding/repository header, real conversation and Message field with one model/effort bar. Tabs below the header; the sidebar fits beside the main view when wide. F10 opens Proof for task-bound sessions and Plan otherwise. Context has one ambient owner, rail or compact footer. No stacked stock footer or default seven-row status box.
FORM: Public Terminal adapter, optional typed packaged SDK main-view/image-activation hooks, native extension widgets and a rendering-only CustomEditor subclass. No root reparenting, private SDK casts or second agent runtime.
SIGNATURE: Resize between 140, 80 and 52 columns while draft, selection and identity stay intact; permission dialogs keep ownership of input.
EXCLUDED: Full workspace board/evidence/DAG/gallery rollout and missing functional contracts; existing bare/plain/headless paths remain separate.
